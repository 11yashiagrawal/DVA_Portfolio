# Yashi Agrawal | Data Analyst Portfolio

A modern, responsive, and beautifully designed web portfolio built with React and Vite to showcase Data Visualization, Business Intelligence, and Analytics projects. 

## 🚀 Features

* **Glassmorphism Dark Mode UI:** A sleek, developer-focused aesthetic using custom CSS and modern design tokens.
* **Interactive Project Filtering:** Seamlessly filter projects by tools and technologies (Python, Tableau, Excel).
* **Dynamic Modals:** Detailed project popups that display comprehensive project descriptions and live links without leaving the page.
* **GitHub Contribution Streak:** Live integration of your GitHub contribution graph using `react-github-calendar` to showcase consistency and coding activity.

## 📊 Projects Showcased

1. **AirBnB US Analytics (Google Sheets, Python):** Analysed bookings and review patterns to strategise pricing, hosts and property locations to maximise revenue.
2. **YouTube Trending Analytics (Python, Tableau):** Decoded virality on YouTube by analyzing 250k+ records to find key factors driving trending success in the Indian market.

## 🛠️ Tech Stack

* **Frontend Framework:** React 18
* **Build Tool:** Vite
* **Styling:** Pure Vanilla CSS (No heavy UI libraries, fully custom)
* **Icons:** Lucide React
* **Integrations:** React GitHub Calendar

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/11yashiagrawal/DVA_Portfolio.git
   cd DVA_Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the localhost URL provided in the terminal (usually `http://localhost:5173`).
